# Guess Word Game
A small word guessing game where the player answers questions by guessing the correct word letter by letter.

## 🔧 Tech Stack
- HTML5
- CSS3
- JavaScript 
- React

## 📋 Features
- Generate a new question by clicking a button
- Guess the word by selecting the correct letters
- Maximum of 6 attempts per round
- Restart the game at any time
- Simple and responsive user interface

## 🚀 Live Demo
https://guess-word-simple-game.netlify.app/

## 📦 Installation
```bash
npm install
npm run dev 
```
